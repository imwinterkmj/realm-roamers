# 角色设计台账

这里记录项目中的原创角色、敌人和可玩角色。此文件用于整理设计思路，不应直接复制动漫、游戏或其他作品的角色设定。

## 使用规则

- 每个角色使用稳定、原创的 `character_id`，代码和 JSON 数据未来优先引用 ID，而不是显示名称。
- 先写战斗定位与专属机制，再补外观、剧情和台词，避免从已有角色外观反推设计。
- 加入立绘、头像、音乐或音效前，在“素材来源”中记录作者、授权方式和文件路径。
- 若灵感来自某个作品，只记录抽象关键词，例如“高速剑士”“雨夜侦探”；不记录或复刻具体角色名、外观、台词和剧情。

## 角色模板

复制以下模板，填入每一个新角色。

### [草案] 角色显示名称

| 项目 | 内容 |
| --- | --- |
| `character_id` | `example_character` |
| 类型 | 敌人 / 精英 / Boss / 可玩角色 / NPC |
| 战斗定位 | 例如：高爆发、叠毒、护盾、召唤、控制 |
| 核心机制 | 用一句话说明该角色独有的战斗规则 |
| 初始数值 | 生命、攻击、护甲/状态等 |
| 专属卡牌或技能 | 名称、能量、效果、数值范围 |
| 外观关键词 | 服饰、色彩、轮廓、武器、动作；避免复刻已有角色 |
| 性格与动机 | 2–3 句原创描述 |
| 事件或台词方向 | 只写原创内容 |
| 素材来源 | 自制 / 委托 / CC 协议资源（附链接、作者、许可证） |
| 风险检查 | 不使用现有作品的名称、标志、立绘、台词、剧情或可识别造型 |
| 状态 | 灵感 / 设计中 / 已实现 / 已有素材 / 已审核 |
