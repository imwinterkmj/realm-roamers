# 角色设计台账

这里记录项目中的原创角色、敌人和可玩角色。此文件用于整理设计思路，不应直接复制动漫、游戏或其他作品的角色设定。

## 使用规则

- 每个角色使用稳定、原创的 `character_id`，代码和 JSON 数据未来优先引用 ID，而不是显示名称。
- 先写战斗定位与专属机制，再补外观、剧情和台词，避免从已有角色外观反推设计。
- 加入立绘、头像、音乐或音效前，在“素材来源”中记录作者、授权方式和文件路径。
- 若灵感来自某个作品，只记录抽象关键词，例如“高速剑士”“雨夜侦探”；不记录或复刻具体角色名、外观、台词和剧情。

强力 BOSS（高层、关底）

* **刑天【强力战斗 BOSS 首选】**

  典故：和天帝争夺神位，首级被斩，依旧持干戚（盾与战斧）不停战斗。

  技能思路：血量越低攻击越高，无头不死，无法被一击秒杀。
* **夔【海岛 BOSS】**

  独足神牛，声震千里，引动雷雨；群体雷电 AOE 伤害。
* **烛龙（烛阴・最终 BOSS 天花板）**

  钟山之神，人面蛇身，身长千里。

  **睁眼为白昼，闭眼为黑夜，呼气为寒冬，吸气为炎夏。**

  可以设计阶段机制：昼夜交替，切换两套攻击模式。
* **饕餮** （大荒凶兽）

  极度贪婪，不停吞噬一切；机制：持续吞噬你的卡牌，越拖越强。
* **开明兽（昆仑守门 BOSS）**

  身似猛虎，长九个头颅；多部位攻击，需要击破多个头部。
* **西王母（昆仑守关 NPC/BOSS 二选一）**

  原始形象：豹尾、虎齿、善啸，执掌瘟疫与长生；不要直接套用后世仙女形象。

  可以设计成：交易型 BOSS，用生命值换取强力卡牌。

### 低层小怪（森林、山地前期敌人）

1. **狌狌** ：像猕猴、白耳朵，可以直立行走；设定：速度型怪物，提升闪避。
2. **旋龟** ：鸟首蛇尾黑龟，生活山涧；水系防御小怪。
3. **鹿蜀** ：白马、虎纹皮毛、赤色长尾；攻击附带衰弱 debuff。
4. **狸力** ：外形猪，擅长掘土；可以召唤土刺、制造地形障碍。

## 【金・庚锋｜执律剑士】

人设内核：执法度斩邪祟，却不断质疑善恶边界，偏执不懂变通

### 角色被动：锋锐

任意卡牌击杀敌人 → 返还 1 点能量；

获得 2 层【锋锐】（每层所有攻击伤害 + 2，上限 12 层）；

战斗结束清空全部锋锐层数。

### 初始专属遗物：庚纹玄铁剑

拥有≥4 层锋锐时，你的所有攻击卡牌无视 3 点护甲。

## 【木・青杪｜灵木行者】

人设内核：想要拯救万物，却深知生命必有取舍，性格心软、优柔寡断

## 【水・玄汐｜渊汐谋者】
