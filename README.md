# C++ Card Roguelike

一个使用 C++ 制作的卡牌 Roguelike 学习项目。当前阶段为命令行战斗原型；后续会接入 Raylib 图形界面。

## 当前可运行内容

- 玩家每回合恢复 3 点能量；格挡会优先抵消敌人的伤害，并在下一玩家回合清零。
- `打击`（攻击，1 能量，6 伤害）实际对敌人造成伤害；`防御`（防御，1 能量，5 格挡）实际提供格挡。
- 卡牌类型通过 `enum class CardType` 表示，`Card::play()` 使用类型结算效果。
- 战斗使用抽牌堆、手牌、弃牌堆；每回合抽 5 张卡，抽牌堆耗尽时会将弃牌堆洗回。
- 终端输入手牌编号即可出牌；输入 `0` 结束玩家回合，输入 `-2` / `-3` 可随时查看抽牌堆 / 弃牌堆。
- 使用固定随机种子洗牌，因此同一套初始牌组的抽牌顺序可稳定复现，便于调试。
- 首场战斗胜利后，从 3 张随机奖励卡中选择 1 张加入永久卡组，并将更新后的卡组带入下一场战斗。

## 项目结构

```text
include/game/  # 类的声明（.hpp）
src/game/      # 类的实现（.cpp）
src/main.cpp   # 命令行演示与游戏流程入口
assets/        # 后续存放图片、字体等资源
data/          # 后续存放卡牌、敌人等数据
tests/         # 后续存放自动化测试
docs/          # 设计文档、角色台账与许可证说明
```

## 构建（Windows / MinGW）

```powershell
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build
.\build\card_roguelike.exe
```

在 MSYS2 MinGW64 环境中运行上述命令，或确保 `D:\msys64\mingw64\bin` 已加入 `PATH`，以便程序能加载 Raylib 的动态库。

当前 Week 2 Day 1 会打开一个 960 × 540 的窗口，标题为 `Realm Roamers`，并显示 `Raylib is running`。按窗口关闭按钮或 Esc 即可退出。
