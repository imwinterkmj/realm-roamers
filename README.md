# 域上行者

一个使用 **C++20 + Raylib** 制作的轻量卡牌 Roguelike MVP。项目重点是展示游戏循环、战斗领域逻辑、状态机与可点击 UI；它不是 Unity 项目，也不以大量内容或复杂美术为目标。

## 当前可玩内容

- 主菜单：开始一轮冒险或退出游戏。
- 三节点路线：`狌狌战斗 → 休息点 → 旋龟战斗`。
- 战斗：点击手牌出牌、消耗能量、获得格挡或造成伤害、结束回合后敌人行动。
- 卡组循环：抽牌堆、手牌、弃牌堆与弃牌洗回机制。
- 四种基础卡牌：打击、重击、防御、壁垒。
- 结果状态：角色死亡进入失败；完成第二场战斗进入“冒险完成”。

## 操作方式

1. 在主菜单点击“开始游戏”。
2. 在地图点击蓝色高亮节点。
3. 在战斗中点击卡牌使用；右上角的数字是这张牌消耗的能量。
4. 点击“结束回合”让敌人行动。
5. 在休息点点击“点击继续路线”，恢复 20 点生命。
6. 在结算界面点击“返回菜单”，可重新开始一轮。

## 构建与运行（Windows / MinGW）

```powershell
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_CXX_COMPILER=D:/msys64/mingw64/bin/g++.exe
cmake --build build
.\build\card_roguelike.exe
```

项目假定 Raylib 已通过 MSYS2 MinGW64 安装。

## 代码结构

```text
src/main.cpp
  └─ GameApp                 图形主循环、输入、界面状态与绘制
       ├─ MainMenu / Map / Rest / Victory / Defeat
       └─ Battle              出牌、回合、抽弃牌堆与胜负判定
            ├─ Player         生命、格挡、能量、治疗
            ├─ Enemy          生命与固定攻击行为
            └─ Card           类型、费用、数值与效果
```

`GameApp` 负责把鼠标点击转换为游戏操作；`Battle`、`Player`、`Enemy`、`Card` 保持核心规则，避免把战斗计算写进 UI 绘制代码。

## 当前范围与限制

这是作品集基础版，暂不加入数十张卡牌、复杂事件剧情、美术动画、存档、成就或大型爬塔分支。遗物、卡牌升级、更多敌人、山海经/五行主题扩展会等核心 MVP 稳定后再考虑。
